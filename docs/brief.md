# Концепция
Архитектурная редакционная подача: лесной графит, тёплая бумага, светлый оливковый акцент. Prata для заголовков, Golos Text для интерфейса. Вместо вымышленных фасадов — честная графика и обозначенные визуализации. Все три объекта имеют равный вес. Макет поддерживает покупку и аренду без выдуманной доступности.
