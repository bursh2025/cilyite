# Контур Центра
Локальная витрина коммерческой недвижимости. Next.js App Router / React / TypeScript / Tailwind 4, статический экспорт в out и отдельный PHP-обработчик. Админка отложена.

## Запуск
npm install
npm run dev
Адрес: http://localhost:3100. Использовать один сервер проекта. Если порт занят — сначала проверить процесс, не останавливать чужой сайт.

## Проверки
npm run typecheck
npm run lint
Production-сборка только по прямому запросу: npm run build. После неё содержимое out загружается в web-root, включая .htaccess, _next и .txt Next. config.local.php и секреты не копируются. Не очищать хостинг при обновлении.

## Контент
content/properties.json — единый источник карточек и характеристик. content/media-manifest.json — внутренний реестр изображений, не отдавать целиком клиенту. docs/media-guide.md — происхождение и назначение фото. app/fonts — локальные шрифты с OFL.

## Telegram
Форма подготовлена, но по умолчанию отключена. Пример настроек: backend/config.local.php.example. Реальную конфигурацию заполнить только на сервере; хранить секреты вне Git. В приватном storage_dir ведутся квоты и квитанции без контактов. Периодически очищать старые квитанции/квоты по согласованной политике хранения; чистка может позволить повтор старой заявки. Сбой между отправкой и квитанцией может привести к дублю. Никакой exactly-once гарантии нет. Локальный next dev не исполняет PHP, поэтому форма показывает честную недоступность.

## Статус публикации
Сейчас preview с noindex и пустым sitemap. Нет подтверждённого домена/оператора, подключения Telegram и счётчиков. docs/launch-checklist.md содержит необходимые действия. Будущая админка должна публиковать согласованный статический снимок, а не только менять браузерные данные.
